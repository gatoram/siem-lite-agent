# CLAUDE.md

Постійні правила роботи над проєктом SIEM-lite.

## Контекст

- Контекст проєкту (мета, архітектура, компоненти, milestone-план) описаний у
  `PROJECT_BRIEF.md`. Читай його на початку роботи.

## Середовище

- Python запускати через `py -3` (наприклад, `py -3 generate_logs.py`).
  Команда `python` на цій машині перенаправляє в Microsoft Store і не працює.

## Журнал роботи

Після кожного завершеного завдання дописуй у `NOTES.md` запис у форматі:

```markdown
## [дата] Назва кроку
- Промпт: (промпт користувача дослівно)
- Що зроблено: (коротко, 2-4 пункти)
- Проблеми і як вирішено: (якщо були)
- Файли: (які створено або змінено)
```

## Git

- Після запису в `NOTES.md` роби `git commit` з коротким описом українською.
